Micro Machines

I worked on Micro Machines for two years as an Associate Product Designer. I did everything from designing cars to building paper models of playsets. I made injection mold ready CAD and created new product lines like the Mystery Box Playset.

Working on Micro Machines was a cruel exercise in cost reduction. It was a $20 million brand that paid $2 million to license it from Hasbro and spent $17 million to operate. Our margins for toys were very thin at a time when manufacturing was seeing major disruptions from the COVID crisis.

In the end, the relaunched '80s brand was wound down aside from a few evergreen products that live on, like the Corvette Raceway playset I originally designed out of cardboard on my living room floor.

Artie 3000

Artie 3000 was a simple drawing robot designed at Educational Insights before I joined the team. It was originally an inventor submission based on the ESP8266. Around the time the ESP32 was becoming the new standard, I did extensive prototyping for a V2 of Artie, eventually released as Artie Max.

Artie was a toy designed to teach children programming using basic JavaScript, Python, or Scratch. During the holiday season I worked on Artie, I developed a simple randomized snowflake script that was distributed online for download. The script chose a random number of arms and designs along each arm to draw a unique snowflake pattern every time.

Gabber

Gabber was an early AR/AI chatbot released on the Meta Quest Store. Developed in early 2023 after the launch of ElevenLabs and GPT-4, it used a custom multi-threaded harness for contextual and emotional inference, along with early versions of LiveKit for low-latency voice streaming.

We achieved >300 ms latency with around a 1.5-second conversation start time. Users could interrupt, emotional sentiment could trigger animations, and we could create a variety of character agents. Ready Player Me was used for avatars.

On Gabber I led the design and UI direction. I created a nostalgic 90s look that was fun and lighthearted, emphasizing the cartoon likeness of our avatars.

Zesty Market

Zesty Market was an in-game ad network targeting WebXR games, now rebranded to Borellien.

From 2022 to 2023, when I was Head of Product, we grew our unique monthly visitors from 150k to 300k. Based on total Quest headsets sold at the time, this was close to 2% of all Quest users and roughly equivalent to the total number of users playing WebXR games in the Quest browser.

Alongside Wonderland and Hey.vr, we had the most direct insight into the development of WebXR outside of Meta's internal teams.

Auto Chop Saw

Back in July I signed up for a hackathon at Founders Inc to give myself some accountability and finally built out this CNC chop saw concept with two of my friends, Zach Glabman and Kael Seaver. It was awesome.

We spent about four hours cannibalizing a 3018 and slapping it on the saw. I also wired up a relay to the spindle output so we could turn the bad boy on remotely (we sorta bypassed the safety features for this :D). We learned we needed more torque for some of the motors, but the concept and code worked.

It spawned the project Grblwave to build a more powerful GRBL motion control board, and a V2 made of sheet metal is in the works. We placed top ten in the hackathon and won a $100 gift card that was indefinitely delayed in transit...

popkorn

popkorn is a non-sequential operation kernel designed to help machine commonly manufactured parts.

  • a bunch of nodes in graphs which can be evaluated for various outcomes
  • intentionally as simple as possible
  • trying to avoid becoming another b-rep kernel, maybe someday b-rep evaluation
  • stores minimal data and throws out a lot

it is made up of a handful of parts:

graphs

operation intent graph

  • stores design features and modeling intent
  • can evaluate to gcode operations, rendered meshes, and(maybe someday) STEP format

evaluation graph

  • stores evaluated data on a component basis
  • can be thrown away and re-evaluated at will

validators

  • validates graph inputs with error reporting for when things break
  • pays attention to both schema and content

evaluators

  • generates gcode and data to construct meshes
  • outputs to common model formats like GCODE, STL, or STEP

interpretor

  • triggers inferred evaluations based on modeling intent

development plan

v0.0.1

  • create a basic graph and root node schema [X]
  • enforce data type and graph ownership [X]
  • generate a node of some type [X]
  • define a tool node [X]
  • define a stock node [X]
  • define an operation node [X]

docker-good-boy

Hey guys, I domesticated Docker! A silly little script that wraps docker compose commands, mostly useful because of docker-rollover.

Tricks

  • docker-sit <optional-container-name> : docker compose pause
  • docker-up <optional-container-name> : docker compose up -d
  • docker-down <optional-container-name> : docker compose down
  • docker-rollover : docker-compose down && - docker-compose build --no-cache && docker-compose up -d
  • docker-good-boy && docker-gb : docker ps && echo \"woof\"

How To Train Your Dog

  1. Git clone this project and navigate to the project folder.
  2. Run chmod +x docker_good_boy.sh.
  3. If you get the ~/.zshrc not found! error, make one using touch ~/.zshrc.
  4. Then, run ./docker_good_boy.sh to add the aliases to your ~/.zshrc.
  5. Reload you /.zshrc with source ~/.zshrc.

Updating

All you should need to do is repeat the above steps, but if you run into issues try:

  1. Clearing the aliases and functions manually with nano ~/.zshrc then repeat the above steps.

robot rally

Robot Rally was an early WebXR looter shooter demo, likely the first non-native multiplayer shooter game to exist in WebXR. At the time and still today, many VR/AR games target the native Quest platform.

We developed Robot Rally as an experiment in how we could grow our in-game XR ad network, Zesty Market, by building games of our own. We eventually pivoted in another direction, but it was here that I did my early exploration with Three.js.

On Robot Rally, I led the concept and graphic design, hand-drew the characters and menus, modeled the first player avatars, and designed the maps and gameplay.
